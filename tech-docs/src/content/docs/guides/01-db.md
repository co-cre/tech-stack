| | D1 | CloudSQL | Firestore |
|--|-----|----------|-----------|
| 本質 | SQLite | PostgreSQL | NoSQL |
| 向いてる | 小〜中規模、読み多め | 複雑なクエリ、大規模 | リアルタイム |
| Drizzle対応 | ○ | ○ | × |
| コスト | 安い | 高め | 読み書き課金 |

## デフォルト: D1 + Drizzle

SQLという枯れた技術。Cloudflareに閉じてシンプル。

### 選定理由

- SQLiteベースで学習コスト低
- Cloudflare Workersとネイティブ統合
- 無料枠が大きい
- Drizzleで型安全

### 向いているケース

- 小〜中規模アプリ
- 読み取りが多い
- Cloudflareで完結したい

### 向いていないケース

- 複雑なJOIN多用
- 大量の同時書き込み
- 厳密なトランザクション必須

## CloudSQL (PostgreSQL)

GCPのマネージドPostgreSQL。

### 選定理由

- フル機能のRDBMS
- 複雑なクエリ対応
- 実績豊富

### 向いているケース

- 大規模アプリ
- 複雑なレポート・分析
- GCPメインの構成

### 向いていないケース

- エッジ実行が必要
- コスト最小化したい
- シンプルなCRUD

## Firestore

Firebaseのドキュメントデータベース。

### 選定理由

- リアルタイム同期
- Firebase Auth統合
- スケーラブル

### 向いているケース

- リアルタイム更新（チャット等）
- Firebase Auth使用
- NoSQLが適切なデータ構造

### 向いていないケース

- 複雑なクエリ
- Drizzle使いたい
- RDBの方が適切

## 選定フローチャート

```
リアルタイム同期必要？
├── Yes → Firestore
└── No
    └── 複雑なクエリ・大規模？
        ├── Yes → CloudSQL
        └── No → D1
```
