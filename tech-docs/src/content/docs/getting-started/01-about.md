## 目的

このドキュメントは、チームの技術選定とその理由を透明化し、全員で共有するためのものです。

## 対象読者

- チームメンバー
- 新規参画者
- AIアシスタント（Claude、Cursor等）

## 構成

| セクション | 内容 |
|------------|------|
| 原則 | 設計思想、判断基準 |
| スタック | 採用技術と選定理由 |
| パターン | 実装の定石 |
| ガイド | 案件ごとの選定基準 |

## 更新方針

- 技術選定時にADR（選定理由）を追記
- 実装パターンが定まったら追加
- 定期的に見直し、陳腐化したものは更新または削除
