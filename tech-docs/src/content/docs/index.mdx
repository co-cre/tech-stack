**Simple over Easy** - 技術選定の透明性を高め、チーム全体で共有する

## 設計原則

1. **必要になったら足す**: 最初から入れない。辛くなったら足す
2. **Web標準に寄せる**: 独自APIより標準API
3. **依存を減らす**: ライブラリは厳選
4. **IFに対してテスト**: 実装詳細ではなく公開インターフェースをテスト
5. **外部IOは型で守る**: URLパラメータ、APIレスポンス等はzodでバリデーション
